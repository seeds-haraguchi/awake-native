# Awake 利用ガイド

Awake は MacBook の蓋を閉じている間もスリープを防ぎます。手元の Mac で動く Codex Remote や Claude Code Remote Control のセッション、SSH 接続、ダウンロードなどを続けたいときに使えます。

## インストール

macOS 13 Ventura 以降の Apple シリコン搭載 Mac と Intel Mac に対応しています。

1. [GitHub の最新リリース](https://github.com/seeds-haraguchi/awake-native/releases/latest)を開き、`.dmg` ファイルをダウンロードします。
2. DMG をダブルクリックして開き、表示された `Awake.app` を `Applications` フォルダへドラッグします。
3. 「アプリケーション」フォルダから Awake をダブルクリックして起動します。初回起動時に確認画面が出たら、内容を確認して「開く」を選びます。
4. 画面右上のメニューバーに月のアイコンが表示されれば起動完了です。Awake は Dock に表示されません。DMG は取り出してかまいません。

DMG の中から直接起動せず、必ず「アプリケーション」フォルダに入れてから起動してください。

## 初回の許可

Awake を初めて ON にするとき、macOS からバックグラウンドで動く補助プログラムの許可を求められます。

1. メニューバーの月のアイコンを開き、右上のスイッチを ON にします。
2. 許可を求めるメッセージが出たら「ログイン項目設定を開く」を選びます。
3. 「システム設定」>「一般」>「ログイン項目と機能拡張」の「バックグラウンドでの実行を許可」で Awake を有効にします。macOS 14 以前は「一般」>「ログイン項目」にあります。
4. Awake のメニューに戻り、もう一度 ON にします。状態欄が ON になり、メニューバーのアイコンが太陽に変われば完了です。

Mac の設定によっては、管理者パスワードの入力が必要です。

## 使い方

メニューバーのアイコンを開くと、次の項目を設定できます。

| 項目 | 動作 |
| --- | --- |
| 右上のスイッチ | Awake の ON / OFF を切り替えます |
| 状態欄 | バッテリー残量、電源、温度状態、タイマーの残り時間を表示します |
| タイマー | オフ、1・2・4・8 時間、任意の時間（1 分～7 日）から選べます。時間が来ると自動で OFF になります |
| バッテリー保護 | オフ、10%・20%・30% から選べます。選んだ残量に達すると自動で OFF になります。AC 電源接続中は働きません |
| 温度保護 | 高温状態が 3 分続くと自動で OFF になります |
| ログイン時に起動 | Mac にログインしたときにアプリを起動します。Awake は OFF の状態で始まります |

作業を始めてから Awake を ON にし、終わったら OFF にしてください。自動で OFF になった場合は、メニューに理由が表示されます。

**ON のまま MacBook をバッグに入れないでください。** 蓋を閉じてもスリープしないため、本体が熱くなり、バッテリーも減り続けます。持ち運ぶ前に OFF にしてください。

## 更新とアンインストール

更新するときは Awake を OFF にして終了し、新しい DMG から `Awake.app` を「アプリケーション」フォルダへドラッグします。置き換えの確認が出たら、古いアプリを置き換えてから起動してください。起動直後は補助プログラムの入れ替えで、スイッチがしばらく操作できないことがあります。

アンインストールは Awake のメニュー下部にある「アンインストール…」から行います。確認画面で実行すると、スリープ設定を戻し、補助プログラムとログイン項目の登録、保存した設定を削除して、`Awake.app` をゴミ箱へ移動します。

## うまくいかないとき

### ON にできない

Awake が「アプリケーション」フォルダにあることと、「バックグラウンドでの実行」が許可されていることを確認してください。許可後も ON にできない場合は、Awake を終了して起動し直します。

### OFF にしたのにスリープしない

ターミナルで `pmset -g | grep SleepDisabled` を実行します。`SleepDisabled 0` なら、Awake が変更した設定は戻っています。`SleepDisabled 1` の場合は、Awake を起動して 1 分ほど待ち、もう一度確認してください。

それでも `1` のままで、ほかのアプリがこの設定を使っていないことを確認できた場合は、次のコマンドで戻せます。Mac の管理者パスワードが必要です。

```bash
sudo pmset -a disablesleep 0
```
