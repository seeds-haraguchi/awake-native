# Awake 試用ガイド

Awake は、MacBook の蓋を閉じてもスリープさせずに処理を続けるための、メニューバー常駐アプリです。
SSH 接続、ダウンロード、ビルド、バックアップなど、長時間かかる作業を蓋を閉じたまま続けたいときに使います。

このガイドは、社内で試用していただく方向けの手順書です。

> **配布場所**: 【ここに DMG の共有先を記入】
> **フィードバック先**: 【ここに連絡先（Slack チャンネルなど）を記入】

---

## ⚠️ 最初に必ずお読みください

- **Awake が ON のままバッグに入れないでください。** 蓋を閉じてもスリープしないため、バッグの中で本体が熱くなり、
  バッテリーも減り続けます。持ち運ぶ前に必ず OFF にしてください。
- 試用版です。大切な作業の途中で初めて使うのは避け、まずは影響の少ない作業で試してください。
- アプリのインストールには **Mac の管理者パスワード** が必要になる場合があります。
- 会社の管理下にある Mac では、セキュリティ設定によってインストールや許可ができないことがあります。その場合は
  フィードバック先にご連絡ください。

## 動作環境

- macOS 13 Ventura 以降
- Apple シリコン（M1 以降）と Intel のどちらの Mac でも動作します
  - **Intel Mac をお使いの方の結果は特に参考になります。** ぜひご報告ください。

## 1. インストール

1. 配布場所から `Awake.dmg` をダウンロードします。
2. `Awake.dmg` をダブルクリックして開きます。
3. 表示されたウインドウで、**Awake** のアイコンを **Applications**（アプリケーション）フォルダにドラッグします。
4. 「アプリケーション」フォルダから **Awake** をダブルクリックして起動します。
   - 「インターネットからダウンロードされたアプリケーションです。開いてもよろしいですか？」と表示されたら
     **開く** をクリックします。
5. 画面右上のメニューバーに 🌙 のアイコン（Awake が OFF の状態）が表示されれば起動完了です。
   - Awake は Dock には表示されません。
6. ウインドウの DMG は取り出して（ゴミ箱へドラッグ）かまいません。

> 必ず「アプリケーション」フォルダに入れてから起動してください。ダウンロードフォルダや DMG の中から直接起動すると、
> 正しく動作しません。

## 2. 初回の許可（最初の 1 回だけ）

Awake は、スリープ設定を変更するための小さな補助プログラム（ヘルパー）を macOS に登録します。
初めて ON にするときだけ、macOS の許可が必要です。

1. メニューバーの 🌙 アイコンをクリックし、右上のスイッチを **ON** にします。
2. 「「システム設定」>「一般」>「ログイン項目」でAwakeを許可してから、もう一度お試しください。」と表示されたら、
   **ログイン項目設定を開く** をクリックします。
   - 「バックグラウンド項目が追加されました」という通知が出ることもあります。
3. 「システム設定」の **一般 > ログイン項目と機能拡張**（macOS 14 以前は **一般 > ログイン項目**）で、
   「バックグラウンドでの実行を許可」の一覧にある **Awake** のスイッチを ON にします。
   - 管理者パスワードを求められたら入力します。
4. Awake のメニューに戻り、もう一度スイッチを **ON** にします。
5. メニューの「Awake」の欄が **ON** になり、メニューバーのアイコンが ☀️ に変われば成功です。

## 3. 使い方

メニューバーのアイコンをクリックすると、次の画面が開きます。

| 項目 | 内容 |
|---|---|
| 右上のスイッチ | Awake の ON / OFF を切り替えます |
| 状態表示 | Awake の状態、バッテリー残量、電源（AC / バッテリー）、温度状態、タイマーの残り時間を表示します |
| タイマー | 指定した時間が過ぎると自動で OFF にします。オフ / 1 時間 / 2 時間 / 4 時間 / 8 時間 / 任意時間（1 分〜7 日）から選べます |
| バッテリー保護 | バッテリー残量が指定した値（10% / 20% / 30%）まで減ると自動で OFF にします。AC 電源につないでいる間は働きません |
| 温度保護 | 本体の温度が高い状態が 3 分間続くと自動で OFF にします。ON のままにしておくことをおすすめします |
| ログイン時に起動 | ON にすると、Mac にログインしたときに Awake を自動で起動します。起動するだけで、Awake 自体は OFF の状態で始まります |
| Awakeを終了 | アプリを終了します。ON の状態で終了した場合も、自動で OFF に戻してから終了します |

### 基本的な流れ

1. 長時間かかる作業を始めます。
2. 必要に応じてタイマーを設定し、スイッチを **ON** にします。
3. 蓋を閉じても作業が続きます（画面は消えます）。
4. 作業が終わったら、蓋を開けてスイッチを **OFF** にします。

自動で OFF になったときは、メニューに理由（「タイマーが終了したため、Awakeをオフにしました」など）が表示されます。

## 4. 試していただきたいこと

できる範囲でかまいません。結果（うまくいった / いかなかった）をフィードバック先にお知らせください。

1. **基本操作**: ON / OFF を切り替え、アイコンと表示が正しく変わるか
2. **蓋を閉じる**: ON にして、時間のかかる作業（大きなファイルのダウンロードなど）を実行したまま蓋を閉じ、
   しばらくして開いたときに作業が続いていたか
3. **タイマー**: 「任意時間」で短い時間（例: 5 分）を設定して ON にし、時間が来たら自動で OFF になるか
4. **バッテリー保護**: AC 電源を外した状態で、現在の残量以上の値を選んで ON にし、すぐに自動で OFF になるか
5. **ON のまま終了**: ON のまま「Awakeを終了」を押し、次に起動したとき OFF になっているか
6. **いつもどおりのスリープ**: OFF にしたあと、蓋を閉じると通常どおりスリープするか

## 5. うまくいかないとき

### OFF にしたのに蓋を閉じてもスリープしない

「ターミナル」アプリを開いて、次のコマンドを実行してください。

```bash
pmset -g | grep SleepDisabled
```

- `SleepDisabled 0` と表示された場合: スリープ設定は元に戻っています。
- `SleepDisabled 1` と表示された場合: Awake を起動して 1 分ほど待ち、もう一度確認してください。それでも `1` のままなら、
  次のコマンドで元に戻せます（管理者パスワードの入力が必要です）。

  ```bash
  sudo pmset -a disablesleep 0
  ```

  このときは、何をしたときに起きたかをフィードバック先にお知らせください。

### アプリが落ちた・反応しなくなった

Awake が突然終了しても、補助プログラムが 1 分以内に自動でスリープ設定を元に戻します。
念のため、上の方法で `SleepDisabled 0` になっていることを確認してください。

### 「許可」の画面に Awake が表示されない

1. Awake を終了し、「アプリケーション」フォルダに入っていることを確認します。
2. Awake を起動し直して、もう一度スイッチを ON にします。
3. それでも表示されない場合は、会社の管理設定で制限されている可能性があります。フィードバック先にご連絡ください。

## 6. 新しいバージョンに更新する

1. Awake を **OFF** にして、「Awakeを終了」で終了します。
2. 新しい `Awake.dmg` を開き、Awake を「アプリケーション」フォルダにドラッグします。
3. 「置き換えますか？」と聞かれたら **置き換える** を選びます。
4. Awake を起動します。通常は、許可をやり直す必要はありません。

アンインストールしてから入れ直す必要はありません。

## 7. アンインストール

1. メニューバーの Awake アイコンをクリックします。
2. 画面下部のバージョン表示の横にある **アンインストール…** をクリックします。
3. 確認画面で **アンインストール** をクリックします。
4. 「アンインストールが完了しました」と表示されたら **終了** をクリックします。

Awake が自動で OFF に戻り、補助プログラムの登録と設定を削除し、Awake.app をゴミ箱に移動します。
完了画面に `sudo pmset -a disablesleep 0` を実行するよう表示された場合は、ターミナルで実行してください。

## フィードバックの送り方

次の情報を添えていただけると、原因を調べやすくなります。

1. **Awake のバージョン**: メニュー下部の「バージョン 0.1.0 (1)」のような表示（文字を選択してコピーできます）
2. **Mac の機種とチップ**: Apple メニュー >「この Mac について」で確認できます（例: MacBook Air M2、MacBook Pro Intel）
3. **macOS のバージョン**: 同じく「この Mac について」に表示されます（例: macOS 15.5）
4. **何をしたら、どうなったか**: 操作の手順と、表示されたメッセージ（スクリーンショットがあると助かります）
5. **起きた日時**: おおよそで構いません

開発者から依頼があった場合は、ターミナルで次のコマンドを実行し、出力をファイルにして送ってください
（直近 1 時間分の補助プログラムの記録です）。

```bash
log show --last 1h --predicate 'subsystem == "jp.co.seeds-std.Awake.Helper"' > ~/Desktop/awake-log.txt
```
